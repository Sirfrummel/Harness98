OPENROUTER CURL TEST FOR WINDOWS 98
==================================

1. Copy this entire folder to the Windows 98 hard drive.
   C:\ORCURL is a good destination.

2. Open the copied folder and double-click TEST_CURL.BAT.

3. If the test succeeds, MODELS.JSN will contain OpenRouter's public
   model list. No OpenRouter API key is needed for this test.

Keep CURL.EXE, CACERT.PEM, and TEST_CURL.BAT together in one folder.
